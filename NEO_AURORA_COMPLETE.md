## 🎨 Customization Guide

### Change Colors
Edit the CSS variables in `index.html`:
```css
:root {
    --base-dark: #0B1021;
    --violet: #7C3AED;
    --fuchsia: #EC4899;
    --emerald: #10B981;
}
```

### Adjust Animations
Find the animation in the `<style>` section:
```css
@keyframes float {
    /* Modify orb movement */
}
```

### Add New Agent Types
In the JavaScript section:
```javascript
function getAgentClass(agent) {
    // Add your custom agent styling
    if (agentLower.includes('myagent')) return 'agent-custom';
}
```

### Change Fonts
Update the Google Fonts import:
```html
<link href="https://fonts.googleapis.com/css2?family=YourFont&display=swap">
```

## 🐛 Known Issues & Solutions

### Issue: Orbs not animating smoothly
**Cause**: Hardware acceleration disabled
**Fix**: Enable in browser settings

### Issue: Backdrop blur not working
**Cause**: Browser doesn't support backdrop-filter
**Fix**: Update to latest browser version

### Issue: Copy button not working
**Cause**: Clipboard API not available (HTTP instead of HTTPS)
**Fix**: Use localhost (which allows clipboard access)

### Issue: File upload not working
**Cause**: File size too large
**Fix**: Ensure image is < 5MB
